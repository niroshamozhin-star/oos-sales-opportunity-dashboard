============================================================

Separate deterministic business logic from AI capabilities.

- Date filtering

- Aggregations
- State filtering

- Dashboard metrics

USE AZURE AI FOUNDRY FOR:

- Natural-language understanding
- Carrier information lookup
- Conversational sales questions
- Grounded outreach message generation

Do NOT ask the LLM to:

- calculate KPI counts
- assign salespeople
- calculate dates
- perform database aggregation
- manage opportunity status

The solution should demonstrate this architectural principle:

"Use AI where AI adds value. Use deterministic application logic where
deterministic logic is more reliable, predictable and cost-effective."
